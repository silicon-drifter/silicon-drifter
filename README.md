# hi, I'm building at the silicon level 👋

An aspiring Embedded Software & Automotive HMI Engineer passionate about bridging the gap between low-level hardware communication and high-level graphical interfaces. Transitioning from modern web development to bare-metal hardware, I specialize in building robust "Black Box" architectures for microcontrollers.

### 🚀 What I'm currently working on

*   **Automotive 3D HMI Dashboard:** Architecting a system that connects an ESP32 hardware backend (gathering raw I2C sensor telemetry) to a custom Qt C++ / QML frontend via QSerialPort.
*   **Bare-Metal Hardware Drivers:** Writing custom I2C communication wrappers from scratch in C (ESP-IDF) for sensors like the Bosch BMP280 and MPU6050. I focus on manipulating memory pointers and hardware registers directly, completely avoiding standard Arduino libraries.
*   **System Architecture:** Designing Finite State Machines (FSM) and data pipelines for embedded IoT devices.
